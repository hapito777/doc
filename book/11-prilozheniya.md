# Приложения

## Разговорник (русский — испанский)

Ниже — минимальный набор фраз, произношение дано русской
транскрипцией. Ударение обозначено заглавной гласной.

### Вежливость

| Русский                       | Español                        | Произношение                |
|-------------------------------|--------------------------------|------------------------------|
| Здравствуйте                  | Buenos días / Buenas tardes    | бУэнос дИас / бУэнас тАрдес  |
| До свидания                   | Adiós / Hasta luego            | адьОс / Аста луЭго           |
| Пожалуйста                    | Por favor                      | пор фавОр                    |
| Спасибо (большое)             | (Muchas) gracias               | (мУчас) грАсиас              |
| Не за что                     | De nada                        | де нАда                      |
| Извините                      | Perdón / Disculpe              | пердОн / дискУльпе           |
| Да / Нет                      | Sí / No                        | си / но                      |
| Я не понимаю                  | No entiendo                    | но энтьЕндо                  |
| Говорите медленнее            | Hable más despacio, por favor  | Абле мас деспАсио            |
| Вы говорите по-английски?     | ¿Habla inglés?                 | Абла инглЕс                  |

## Источники и рекомендуемое чтение

- **Afonso, L. (ред.)** *Historia de Canarias.* — Santa Cruz, 2008.
  Канонический учебник канарской истории.
- **Cabrera Pérez, J. C.** *Los primeros canarios.* — Madrid, 2017.
  Доступная популярная книга о канарио.
- **Martín, C.** *Geografía de Canarias.* — Madrid, 2006. Богато
  иллюстрированный научно-популярный атлас.
- **Sabaté Bel, F.** *Senderos de Gran Canaria.* — Las Palmas, 2020.
  Лучший путеводитель по пешеходным маршрутам.
- **Perera Betancort, M. A.** *La cocina tradicional canaria.* —
  Las Palmas, 2012. Рецепты и этнографический контекст.
- **Galdós, B. P.** *Episodios Nacionales.* — Мадрид, 1872–1912.
  Исторические романы главного канарского писателя.
